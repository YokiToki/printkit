# Free Editor — главный режим PrintKit

Свободный редактор (`/editor`) — основной продукт сайта: импорт и правка STL и создание моделей с нуля по эскизам. Gridfinity, Keychain и Rack остаются **генераторами** — быстрыми параметрическими режимами «заполни поля, получи деталь». Редактор — «сделай что угодно».

Документ — исследование и общий план серии changes `39`–`45` (порядок и зависимости в `ROADMAP.md`). Полные артефакты (proposal, specs, design, tasks) написаны для `39`; для `40`–`45` ниже зафиксированы границы, чтобы при `/opsx:propose` не терять решения.

## 1. Что берём из настольных редакторов

Смотрели не «что умеет всё», а чем **пользуются каждый день при подготовке деталей к печати**.

| Редактор | Модель работы | Что перенимаем | Что осознанно не берём |
|---|---|---|---|
| **Tinkercad** | Примитивы + «solid/hole», группировка (булевы) | Палитра примитивов, hole/solid, выравнивание, линейка-рабочая плоскость, «прилипание» к столу, очень низкий порог входа | Ограниченная точность ввода |
| **Fusion 360 / Onshape / SolidWorks** | Эскиз на плоскости → ограничения и размеры → Extrude/Revolve → дерево операций (timeline) | Эскиз с ограничениями и размерами, Extrude (join/cut/new), Revolve, Fillet/Chamfer, Shell, Pattern/Mirror, дерево с возвратом к шагу, правка параметров любого шага | Сборки, соединения, анимация, поверхностное моделирование, симуляция |
| **FreeCAD (Part Design / Sketcher)** | То же, открытый солвер ограничений (planegcs) | Идея ограничений как данных; список ограничений, степени свободы (DoF) в строке состояния | Рабочие столы (workbenches), Python |
| **Shapr3D / Plasticity** | Direct modeling: тянуть грань | «Push/Pull» по грани (эквивалент Extrude по грани), выбор грани как плоскости эскиза | Жесты планшета |
| **Blender** | Полигональная сетка, модификаторы | Модификаторы как неразрушающий стек (Mirror, Array, Boolean, Decimate, Solidify=Shell), горячие клавиши G/R/S, привязки (snap), Origin, Apply | Скульптинг, UV, материалы, рендер, анимация |
| **Meshmixer / 3D Builder / netfabb** | Работа с STL «как есть» | Авторемонт (дыры, нормали, самопересечения), Plane Cut, Hollow (с отверстием для слива), Make Solid, Reduce (Decimate), Smooth, Align/Lay Flat, Measure, Analysis (нависания, толщина стенки) | Скульптурные кисти, поддержки «в дереве» |
| **Слайсеры (Bambu Studio, PrusaSlicer, OrcaSlicer)** | Плита, ориентация | Cut Tool (плоскость, шипы/пазы-соединители), Lay on Face, Arrange, Mirror, Scale, «Drop to bed» | Слайсинг, G-code |

### Общие для всех приёмы взаимодействия (обязательный минимум)

- Орбита / панорама / зум мышью и тачем, **ViewCube** и стандартные виды (Top/Front/Right/Iso), перспектива ↔ ортографика, Fit all / Fit selection.
- Выбор: клик, Shift/Ctrl — добавить, рамка, выбор из списка (outliner), Esc — снять; выбор **грани / ребра / тела** как режимы.
- Гизмо перемещения / поворота / масштаба (стрелки, кольца, ручки), **числовой ввод** в панели, привязка (шаг сетки, шаг угла, к граням/вершинам), «положить на стол», «положить гранью».
- Дерево объектов (outliner): имя, видимость, блокировка, дубль, удаление, цвет.
- **Undo / Redo** на всё, горячие клавиши, контекстное меню, подсказки с хоткеями.
- Рабочая плоскость и сетка с понятным масштабом; измерения (расстояние, габариты, объём).
- Единицы: мм внутри, дюймы на вводе (уже есть `LengthField`).

### Эскиз (чертёж на плоскости) — как это устроено в CAD

1. Выбрать плоскость (XY / XZ / YZ, грань тела, смещённая плоскость) → вход в режим эскиза: камера смотрит нормально к плоскости, сетка 2D.
2. Инструменты: линия/полилиния, прямоугольник (по двум углам, по центру), окружность (центр-радиус), дуга (3 точки / центр), многоугольник, эллипс, сплайн, текст, точка/конструкционная геометрия.
3. Правка: Trim, Extend, Offset, Fillet/Chamfer 2D, Mirror, Pattern, Move/Rotate/Scale.
4. **Ограничения** (constraints): совпадение, горизонтально/вертикально, параллельно/перпендикулярно, касательно, равно, симметрично, фиксация, точка на кривой; **размеры** (длина, радиус/диаметр, угол, расстояние) — это параметры, которые правятся числом (и в будущем формулами/переменными).
5. Индикатор «степеней свободы» (недоопределён → синий, определён → чёрный/зелёный, переопределён → красный), автопредложение ограничений при рисовании (хоризонталь/вертикаль/касание «прилипают» сами).
6. Профиль должен быть **замкнутым** для твёрдого тела; индикация разрывов и самопересечений.
7. Выход: Extrude (расстояние, симметрично, два направления, угол уклона, до тела), Revolve (ось, угол), позже Sweep/Loft; результат — join / cut / intersect / новое тело.
8. Импорт контура: SVG и DXF, сечение STL плоскостью, обводка растра (уже есть трассировка силуэтов из Keychain/Cutout — переиспользуем).

### Правка STL (сетка) — самые востребованные операции

| Группа | Операции |
|---|---|
| Положение | Move/Rotate/Scale, Lay on Face, Drop to bed, Center, Align/Distribute, Mirror, масштаб до размера |
| Диагностика | Замкнутость (дыры, не-манифолд, самопересечения, нормали), «здоровье» сетки, габариты, объём, толщина стенки, нависания |
| Ремонт | Weld, Fill holes, Flip normals, удалить мусорные оболочки, Make Solid (воксельный/manifold ремонт) |
| Разрез | Plane Cut (одна или две стороны), Split на части с **соединителями** (шипы, ласточкин хвост — уже есть в `connectors.ts`), разрез по размеру стола |
| Булевы | Union / Difference / Intersection между телами (manifold даёт это из коробки) |
| Тело | Hollow/Shell (стенка, дренажное отверстие), Offset (утолщение), Fillet/Chamfer выбранных рёбер, Reduce (decimate), Smooth |
| Массивы | Linear / Circular Pattern, Mirror-копия |
| Добавить | Текст (emboss/engrave, уже есть растеризация), Primitive (куб, цилиндр, сфера, конус, тор, клин, пирамида), Hole/Counterbore/Thread-посадка |

## 2. Модель документа (ядро, определяет всё остальное)

Три уровня, выбор — **объекты со стеком операций** (как «Blender: модификаторы» + «Fusion: timeline»):

```
Scene
 └─ Object { id, name, visible, locked, color, transform(position, rotation, scale) }
     └─ source:  mesh(meshId) | primitive(kind, params) | sketchFeature(sketchId, extrude|revolve…)
     └─ stack:   [Op, Op, …]   // неразрушающие операции, считаются по порядку в воркере
                               // Op = boolean(otherObject), planeCut, hollow, fillet, mirror, array, decimate, …
```

- **Гибридное ядро геометрии (Dual-Engine CAD + CSG)**:
  - **`occt-wasm`** (Open CASCADE Technology 8.0 в WebAssembly, ~5–7 МБ сжатый, загрузка по требованию в Web Worker): полноценное CAD B-Rep ядро для параметрических тел из эскизов, точных 3D скруглений и фасок на рёбрах, нарезки резьбы, стабильного отслеживания граней и прямого экспорта/импорта STEP (AP203/214/242).
  - **`manifold-3d`** (CSG WASM): быстрое полигональное ядро для булевых операций над произвольными STL, разделения деталей под стол 3D-принтера, полостей (Hollow) и экспорта сеток в STL/3MF.
  - **`meshoptimizer`** (WASM): высокоскоростная QEM децимация сеток с фиксацией граничных вершин и двусторонним контролем допуска.
  - **`three-mesh-bvh`**: пространственный индекс для Three.js, обеспечивающий субмиллисекундный raycasting, выбор подэлементов (picking) и расчет карты толщины стенок.
- **Неразрушающий стек операций с префиксным кэшем (`Builder` / `KeptBuild`)**:
  - Каждая операция правится числом или выражением. Дерево операций кэширует промежуточные шаги: при правке шага $k$ шаги $1…k-1$ берутся из кэша, пересчитываются только $k…n$.
  - **Маркер отката (Rollback Bar)**: интерактивная черта в дереве операций, которую можно перетащить мышью вверх для просмотра промежуточного состояния и вставки шагов в середину истории.
  - **Режим Playback**: пошаговый просмотр процесса моделирования.
- **Топологическое именование (Topological Naming Engine)**:
  - Решение проблемы стабильности ссылок на грани и рёбра при перестроении параметрического дерева через геометрические отпечатки (`FaceFingerprint` и `EdgeFingerprint`).
  - Отпечаток хранит аналитический тип поверхности (плоскость, цилиндр, конус, тор), нормаль/ось, центр масс, площадь/радиус и ID создавшей операции. При перестроении связь сопоставляется по минимальной невязке отпечатка, а не по индексам треугольников.
- **Эскиз — данные и взвешенный солвер Левенберга–Марквардта**:
  - Жесткие уравнения ограничений и размеров имеют вес $10^4$ (точность до долей микрона).
  - Свободное удержание геометрии (stay-put) — вес $10^{-1}$, сила перетаскивания курсором (pull) — вес $10^2$.
  - Анализ степеней свободы (DoF) через собственные числа матрицы нормальных уравнений: синий = недоопределен, черный = полностью зафиксирован, красный = конфликт.
  - Автоматический вывод связей на лету (`autoConstrain`).
  - Калькулятор выражений (`expression.ts`) со строгой проверкой размерностей (мм, градусы, скаляры).
- **Приёмы UI/UX взаимодействия в 3D**:
  - **HUD Context Chips («Объект первый, действие второе»)**: клик по грани, ребру или области эскиза открывает контекстные плашки прямо у курсора в 3D (размеры, свойства, быстрые кнопки Extrude, Push/Pull, Fillet, Hole, Thread).
  - **In-Situ 2D Sketching**: ортогональное выравнивание камеры, векторные линии `Line2`, интерактивная заливка замкнутых профилей, выносные размеры с редактированием по месту.
  - **CAD Box Select**: двунаправленная рамка выбора (слева направо = Window/только целиком, справа налево = Crossing/всё коснувшееся).
  - **CAD Edge Shading**: четкая прорисовка рёбер с разделением на острые и касательные (с возможностью приглушения касательных сопряжений).
  - **Живые 3D-ручки (Grips & Live Ghost)**: интерактивные стрелки и дуги на полупрозрачном превью для динамического ввода параметров.
  - **Поддержка 3Dconnexion SpaceMouse**: нативная 6-осевая навигация.
  - **3D-заметки и пины**: установка аннотаций прямо на поверхность детали.
- **Хранение и проект `.pkit`**:
  - ZIP-контейнер (`fflate`): `project.json` (дерево сцены, параметры, эскизы, 3D-заметки), бинарные сетки `meshes/<hash>.bin`, превью `thumb.png`. Защита от ZipSlip и контроль лимитов памяти.
  - Кольцевой буфер автосохранения в IndexedDB для защиты от сбоев.

### Формат файла `.pkit`

- Это ZIP-контейнер (fflate уже в проекте, как для 3MF) с расширением `.pkit` и своим MIME `application/x-pkit+zip`.
- Внутри: `scene.json` (документ: `{format: 'pkit', version, schema, objects, ui}`; длины в мм), `meshes/<id>.bin` (сетки: заголовок + Float32 вершины + Uint32 индексы; id = хэш содержимого, одинаковые сетки хранятся один раз), `sketches/` (эскизы, ограничения и размеры — с `40`), `thumb.png` (превью для списка недавних), `meta.json` (имя, версия приложения, дата).
- Версионирование: поле `version` — версия формата, не приложения; старые файлы читаются через `migratePkit`, файл новее приложения открывается с предупреждением, неизвестные поля сохраняются при пересохранении.
- Безопасность: размер и число записей ограничены, пути внутри архива проверяются (нет `..`), JSON проходит ту же нормализацию, что и `localStorage`; открытие файла ничего не исполняет.
- Операции: «Сохранить» (скачивание `.pkit`, имя из названия проекта), «Открыть» (диалог и перетаскивание на сайт, в том числе на пустой экран), «Новый». В `39` файл ещё не появляется: документ уже хранится в виде, из которого `.pkit` собирается без преобразования (поля `schema`, меш-id по содержимому).

## 2a. Сетка как результат, а не как источник (правило для 40–44)

Выбор `manifold` (сетка) вместо B-rep закреплён так, чтобы его слабости закрывались структурой документа:

1. **Источник — эскиз и параметры операций, сетка — производная.** Тело, построенное из эскиза (Extrude, Revolve, позже операции стека), хранится как `{sketch, feature, params}`; сетка пересчитывается из них и никогда не является единственной копией. Исключение — импортированный STL: его сетка и есть источник.
2. **Разрешение — параметр сборки.** Число сегментов кривых (окружность, дуга, Revolve, сфера) задаётся при пересчёте, а не вшивается; экспорт может пересобрать тело с большим разрешением (по умолчанию 96 сегментов на окружность, для экспорта настройка «Качество»). Булевы между уже собранными сетками не должны накапливать потерю: стек пересчитывается от источников.
3. **Скругления и фаски.** Скругление и фаска углов эскиза строятся точно в 2D (дуга касательная к обеим линиям, ограничение и размер радиуса). Для твердотельных CAD-тел 3D-скругления и фаски выполняются B-Rep ядром `occt-wasm` с сохранением аналитических поверхностей и истории граней. Для импортированных STL-сеток скругление прямых выпуклых рёбер выполняется булевым срезом сопрягающим телом (`manifold-3d`).
4. **Ядро заменяемо и модульно.** Слой «эскиз и операции → тело» (`geometry/features/`) не зависит от React и three.js и выдаёт `ModelResult` / `MeshData`; сцена, импорт STL, экспорт и `.pkit` от конкретного бэкенда не зависят. При необходимости вычислений CAD B-Rep (STEP, точные фаски, скругления, резьба) в воркере подключается `occt-wasm`.
5. **Грани — стабильные ссылки (Topological Naming).** Вместо нестабильных номеров треугольников или полигонов используется отслеживание через отпечатки `FaceFingerprint` и `EdgeFingerprint` (тип геометрии, нормаль/ось, центр масс, радиус, origin feature ID). Для полигональных сеток грани определяются через связные компланарные области (`flatFaces`).

## 5. Риски

- **Объём.** Эскиз с ограничениями — самая большая часть (солвер, UI, пересчёт). Держим v1 маленькой: линия, прямоугольник (с радиусом углов), окружность, дуга, Fillet/Chamfer 2D; 8–10 ограничений; без сплайнов и конструкционной геометрии; остальное добавляется в `44`+.
- **Fillet/Chamfer на сетке.** У manifold нет операции скругления. Для эскизов скругление делаем в 2D (точно); для 3D-рёбер — аппроксимацией (offset + булевы) или ограничиваем рёбра выпуклыми прямыми. Решается в `44` спайком, пока в обещания не входит.
- **Производительность.** Большие STL (> 1 млн треугольников): отображение без перестроения, булевы только по запросу, прогресс в логе `31a`, предупреждение.
- **Выбор граней на сетке.** Граней как B-rep нет: «грань» = связная компонента копланарных треугольников (`flatFaces` уже есть) с допуском; на скруглённых телах выбор по группам нормалей.
- **Лицензия солвера** — условие спайка в `40`: допускаются только разрешающие лицензии либо динамическая загрузка отдельным файлом; иначе — собственный солвер.
- **Не потерять генераторы**: ни один существующий маршрут и ключ хранения не меняется до `45`.
